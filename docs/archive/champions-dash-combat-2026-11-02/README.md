# Archived Rhythm Champions dash-centered combat

Archived on **2026-11-02**, before the combat/progression revision. These are
historical snapshots, not instructions to implement. The [current design](../../champions/design.md),
[plan](../../champions/plan.md) and [style guide](../../champions/style.md) win.

- [Design](design.md): damaging dash types, sparse quiet-held choices, instant
  XP, three attacks/four mods, two cleared boss duels and Break.
- [Plan](plan.md): original implementation sequence and unchanged epic map.
- [Style guide](style.md): prior guide including now-obsolete combat accents.
- [Runtime overview](runtime-readme.md): the implementation before this redesign.

The revision restores positioning-led automatic combat, six weapons and six
broad supports, frequent choices, XP collection and three rhythmic bosses
with retained hordes. Weapon forms are fixed at levels 3/5/8 and preserve
support compatibility. There is no separate evolution recipe or Break system.

Historical [implementation evidence](../../../rhythm_champions/evidence/README.md)
stays at its original paths for traceability. No code or beads changed as part
of this documentation pass; snapshots do not claim the redesign has shipped.
