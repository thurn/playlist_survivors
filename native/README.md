# Native (frozen)

**Frozen on 2026-11-01.** [Rhythm Champions](../docs/champions/design.md) (`rhythm_champions/`) replaces it. It stays in the tree for reference, outside CI: nothing new builds on it, and a change elsewhere may break it unnoticed.

The native Rust game: Playlist Survivors' 30-minute run in 2D pixel art, listening live to any app's music. Its audio plugin and the four crates it uses were copied into `rhythm_champions/plugin/`; this copy no longer changes.

Its design, archived: [native-app.md](../docs/archive/design/native-app.md) and [survivors-run.md](../docs/archive/design/survivors-run.md).
