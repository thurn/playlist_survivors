# FR1 — Main-beat enemy travel

Travel admissions read committed main beats plus the existing sustained reliability
threshold; confidence evidence expires after 250 ms without a current tick. Every
role, swarm, ring and formation uses a <=100 ms / <=20%-period step before its
main-beat footplant. Brutes may take every second beat. Separation is baked into
the destination, roots hold between admissions, and forced recoil remains distinct.
Menu resume discards unfinished pursuit. Contact requires current reliable beat
knowledge and notice; crossing steps use swept contact. Boss slams also require
that admission. Free weapon/player pulses no longer arm enemy contact.

`movement-tests.txt` records tests using shipped catalog roles at 70/128/174 BPM,
the actual timestamped `session-house-delayed` recording, late knowledge, a
confidence gap, missing beats, snapshots, and a mid-step menu pause. This proves
root timing/holds, not visual quality, balanced survival or audible feel.
Existing TS full-event prefix comparisons were retired because their target,
kill, gait and contact timelines demand the deliberately replaced travel rules.
Native frame/snapshot and unchanged legacy judging reference tests remain.

Playable from `native/`:

```
cargo run --release -p app -- --playlist playlists/survivors-30.m3u --delayed
```

Routine agent validation uses `--headless --seconds 30`. Integrated visual,
density, performance, both-mode qualification and speaker checks belong to FR10;
FR2–FR9 build combat, sound, HUD and choreography on this admission rule.

Cold warden review: seven confirmed findings were fixed: scheduled ring hold and
close rate; coalesced repeat debt; actual ring progress after cancellation; legacy
Armour; song-anchored interpolation through rate changes; published in-place contact
notice; and catalog presentation assertions. Regression tests cover these paths.
Historical live world hashes changed with deliberate travel rules; raw sessions
remain intact and now verify settled replay across different rollback horizons.
