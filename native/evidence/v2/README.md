# V2: the slice's sprites, effects and sounds

`still.png`: the slice 8 s into a run at 120 bpm, the hero having just attacked on a beat, drawn
offscreen by the render crate (`playlist-survivors --still <png>`, from the bundle or
`cargo run -p app --release -- --still <png>`). It is the only visual check an agent could make
(no screen capture permission, speakers muted); the window, the sound effects and System mode
wait on the operator (`operator-pending.md`).
