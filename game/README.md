# game (frozen)

**Frozen on 2026-11-01.** [Rhythm Champions](../docs/champions/design.md) (`rhythm_champions/`) replaces it. It stays in the tree for reference, outside CI: nothing new builds on it, and a change elsewhere may break it unnoticed.

The first Unity game: native's 30-minute run in 3D, with its modes (`grid`, `free`, `zen`, `--dash`) and the neon look. Rhythm Champions ports some of its pieces by review (the sim's pattern, the music clock, calibration).

Its design, archived: [unity-game.md](../docs/archive/design/unity-game.md) and [game-modes.md](../docs/archive/design/game-modes.md).
