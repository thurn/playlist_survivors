# Checks waiting on the operator

Checks an agent can't finish alone for the Unity game: they need a window, a click, a device, the
speakers on, or an ear. Clear them in one sitting; the consuming bead re-runs them and records the
result, then removes the row. Add a row whenever a game bead records something as pending on the
operator (epic ps-msz; native's own list is native/evidence/operator-pending.md).

| Delayed listening on the Mac, from the title screen (ps-msz.5.3) | Play music in Music, or in a browser. `just game` opens the title screen in a window: the rainbow wordmark, the app under PLAYING NOW (it appears within a second of starting), files under FILES AND PLAYLISTS (Cmd-V on a copied path adds one); Up/Down and clicks choose. Pick the app and press Enter: macOS asks once for System Audio Recording for Playlist Survivors (allow it; if that first run stays silent, Backspace returns to the title screen, pick it again). The app goes silent at once and its music returns 3 s later, in sync with the knight's strides and the swings' sounds. Backspace: the app's own sound returns at once, the title screen says the run was ended. Then `just game` after a rebuild (`just game-build --force`): no second prompt. Also `just game --app Music` (or the browser's name) straight into a live run | `just game` | ps-msz.5.3 | ps-msz.7 |

| A capture stall on the Mac (ps-msz.5.3) | During a live run on Music, suspend Music, wait 3 s, resume it.
