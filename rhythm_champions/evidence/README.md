# Implementation evidence

These files record specific implementation and visual-review results, not the
current game design. Combat evidence produced before the 2026-11-02 redesign
belongs to the [archived dash-centered design](../../docs/archive/champions-dash-combat-2026-11-02/README.md).
It remains at its original paths so source, tests and historical links work.
It does not validate the redesigned weapons, supports, XP drops or boss loop.

Use [the current design](../../docs/champions/design.md) for gameplay authority
and [the plan](../../docs/champions/plan.md) for migration scope. Rendering,
audio and performance measurements remain useful within their recorded scope.
No bead statuses or recorded results were changed by the documentation pass.
